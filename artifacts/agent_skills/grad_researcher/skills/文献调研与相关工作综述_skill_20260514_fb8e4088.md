# 文献调研与相关工作综述

围绕研究主题收集背景、竞品、论文和已有方案，形成可引用的调研结论。

## 适用场景
需要了解一个课题的背景、已有工作、产品差异、技术脉络或研究空白时使用。

## 操作步骤
1. 先拆出关键词、同义词、英文表达和可比较对象。
2. 按来源类型组织材料：论文、官方文档、产品资料、用户反馈、技术博客。
3. 对每个来源记录核心观点、证据强度、适用范围和不确定性。
4. 横向比较不同来源之间的一致结论与冲突结论。
5. 最后沉淀成综述段落、对比表和后续研究问题。

## 输出要求
避免堆材料，要给出“为什么相关”“能支持什么结论”“还缺什么证据”。
