# 系统设计与工程实现方案

把研究需求转成模块边界、接口、数据结构和可落地的实现步骤。

## 适用场景
需要设计系统架构、实现功能、整理工程边界或为实验提供可运行工具时使用。

## 操作步骤
1. 先识别现有代码结构、数据流、状态流和已有约束。
2. 明确新增模块的职责边界，避免把跨层逻辑写进单个函数。
3. 定义输入输出、错误处理、配置项和后续扩展接口。
4. 优先复用项目既有模式，再考虑新增抽象。
5. 完成后补充最小验证路径，例如语法检查、接口调用或冒烟脚本。

## 输出要求
方案中必须说明改哪些文件、为什么改、如何验证，以及哪些能力当前只预留接口不实现。
