# 数据分析与结论归纳

对实验、调研和任务产出进行指标解释、异常定位和结构化归纳。

## 适用场景
需要从多份调研结果、实验日志、表格或指标中提炼结论时使用。

## 操作步骤
1. 先确认数据来源、采样范围、指标定义和统计口径。
2. 对比不同任务产出的共同点、差异点和冲突点。
3. 标注异常值、缺失信息和可能影响结论的偏差。
4. 用表格或分组清单呈现关键指标。
5. 给写作 Agent 提供可直接使用的结论、证据和限制条件。

## 输出要求
每条结论都要尽量绑定证据来源，不能把未经验证的猜测写成事实。
