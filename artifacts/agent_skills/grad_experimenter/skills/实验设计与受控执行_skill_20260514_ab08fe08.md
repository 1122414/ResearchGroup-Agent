# 实验设计与受控执行

设计可复现实验计划，并在用户批准后通过受控工作区执行命令获得结果。

## 适用场景
需要通过代码、脚本、数据处理或参数对比获得实验结果时使用。

## 操作步骤
1. 明确实验问题、输入数据、变量、对照组、指标和成功标准。
2. 生成实验计划时写清命令、文件、环境变量和预期产物。
3. 执行前进行风险扫描，涉及删除、网络、依赖安装、系统路径或密钥时必须等待用户审查。
4. 只在配置工作区内写入文件和运行命令。
5. 记录 stdout、stderr、退出码、耗时和结果摘要，供分析 Agent 使用。

## 输出要求
实验结论必须区分“观察结果”“可能原因”和“还需要补做的验证”。
