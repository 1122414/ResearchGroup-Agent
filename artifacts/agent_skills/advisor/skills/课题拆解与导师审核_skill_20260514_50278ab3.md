# 课题拆解与导师审核

把研究目标拆成可执行任务，并在阶段产出后进行质量审核。

## 适用场景
当用户提交一个开放式研究目标，或阶段性任务产出需要判断是否可进入最终报告时使用。

## 操作步骤
1. 提取研究对象、比较维度、预期产物和约束条件。
2. 将目标拆成文献调研、工程实现、实验设计、数据分析、写作整合等任务。
3. 为每个任务指定验收标准，避免只给宽泛描述。
4. 审核产出时优先检查事实依据、逻辑闭环、引用痕迹和是否回应研究目标。
5. 对未通过项给出可执行修改意见，而不是泛泛要求优化。

## 输出要求
输出任务拆解或审核结论时应明确：是否通过、主要问题、下一步处理人和需要补充的证据。
