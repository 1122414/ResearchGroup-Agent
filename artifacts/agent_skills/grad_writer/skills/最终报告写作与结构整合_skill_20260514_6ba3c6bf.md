# 最终报告写作与结构整合

汇总各任务已审核结果，形成面向用户可下载的 Markdown 最终报告。

## 适用场景
所有关键调研和实验任务完成，并经过导师审核后，进入最终报告撰写阶段时使用。

## 操作步骤
1. 只整合已完成且通过审核的任务结果，必要时引用导师审核摘要。
2. 先搭建报告结构：研究目标、方法、核心发现、对比分析、结论、局限和建议。
3. 将文献、工程、实验、分析结果转写成连贯段落，而不是简单拼接。
4. 保留关键证据、数据和来源说明。
5. 输出 Markdown，并确保标题层级、列表、表格和下载文件名清晰。

## 输出要求
最终报告必须回应原始课题，语言统一，结论明确，并区分最终报告和阶段性审核报告。
